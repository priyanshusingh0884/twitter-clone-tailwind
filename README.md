# Twitter Clone 🐦

A Twitter-inspired frontend UI clone built using HTML and Tailwind CSS. This project focuses on recreating the look and layout of the Twitter interface while practicing utility-first styling with Tailwind CSS.

## ✨ Technologies Used

- HTML5
- Tailwind CSS v4.3.3
- Tailwind CSS CLI

## 📁 Project Structure

```text
twitter-clone-tailwind/
│
├── index.html
├── package.json
│
└── src/
    ├── input.css
    └── output.css
```

## ⚙️ Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/priyanshusingh0884/twitter-clone-tailwind.git
   ```

2. Navigate to the project directory:

   ```bash
   cd twitter-clone-tailwind
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the Tailwind CSS compiler:

   ```bash
   npx @tailwindcss/cli -i ./src/input.css -o ./src/output.css --watch
   ```

5. Open `index.html` in your browser.
